リポジトリのトップからindex.htmlを生成、または更新するツールです。<br>
<br>
生成する index.html はリダイレクトを行うために、GitHub Pages のルートに<br>
配置することを前提にしています。<br>
<br>
リポジトリのトップから、ルートに index.html が無い場合はファイル作成、<br>
既に index.html が有る場合は、そのファイルを更新する画面を開きます。<br>
<br>
開いた画面で、リダイレクト先のURLを入力して「Set」ボタンを押すと、<br>
そのURLを転送先にする index.html が出力されます。<br>
